1. 系統簡介 (Introduction)

PPT Master 是一套專為生成「原生可編輯」PowerPoint 簡報而生的混合式 AI 引擎。它能將任意檔案（PDF、DOCX、網址、文字檔）轉化為具備頂級設計感的簡報。

核心優勢：真正的 PPTX
市面上許多 AI 工具輸出的是「單張大圖拼湊的簡報」或「網頁版展示」。PPT Master 輸出的是真正的 DrawingML 向量圖形、文字方塊與原生結構。您可以在 PowerPoint 中點選任何一個元素進行顏色、大小、文字的二次編輯。

支援的功能包含：

  • 多檔案解析（PDF / DOCX / URL / NotebookLM）
  • 純原生的 SVG 向量圖形與排版
  • 頁間轉場與物件進入動畫原生支援
  • 自動抓取高畫質商業相簿（Pexels / Pixabay）
  • 支援多語系 TTS 語音旁白與影片匯出

2. 兩種操作模式比較

系統提供兩種操作模式，您可以根據自己的技術背景與客製化需求選擇：

🖥️ 模式 A：Web GUI 全自動模式 (推薦一般使用者)

不需要懂任何程式碼，只要開啟網頁，貼上文字或上傳檔案，系統會自動在背景執行全部流程並提供下載連結。

易用性高全自動

🤖 模式 B：IDE Agent 開發者模式 (推薦進階使用者)

在 VS Code、Cursor 或配合 Antigravity IDE 使用。AI 直接在本地編寫高擬真 SVG 程式碼，您可以隨時介入對話，要求 AI 微調顏色、增刪圖表，最後下達編譯指令。擁有最高階別的設計主導權。

極致客製化即時修改

3. Web GUI 全自動模式操作指南

透過視覺化的介面快速產出簡報。

3.1 啟動伺服器

在命令列 (CMD/PowerShell) 輸入以下指令啟動：

cd c:\Users\USER\Downloads\NBLM_PPT_Pipeline
py gui/backend/app.py
# 或使用 py pptmaster_gui.py

啟動後，開啟瀏覽器並前往 http://127.0.0.1:7070

3.2 設定 API Key (必要步驟)

⚠️ 警告： 網頁模式依賴 LLM 自動生成內容。如果沒有設定 API Key，按下產生時系統會報錯。
  1. 點選右上角的 「設定 (Settings)」 圖示。
  2. 在 AI 模型金鑰 區塊，填入 GEMINI_API_KEY 或 OPENAI_API_KEY。
  3. (可選) 在 相簿 API 金鑰 區塊，填寫 PEXELS_API_KEY 以獲得高畫質配圖。
  4. 點選「儲存設定」。

3.3 開始生成

  1. 回到主畫面，在文字框內貼上您的草稿、筆記或企劃書。
  2. 設定您期望的投影片頁數（例如：10頁）與長寬比（預設 16:9）。
  3. 點選 「開始產生 (Generate)」。
  4. 系統會在背景進行：文字摘要 → 生成 SVG 語法 → 圖片尋找 → PPTX 封裝。完成後會直接跳出下載提示。

4. IDE Agent 開發者模式操作指南

透過 AI 助手（Agent）逐步執行，這是本系統最原始且最強大的工作流。

Step 1: 建立專案與解析素材

# 1. 建立新專案
py skills/ppt-master/scripts/project_manager.py init "my_project" --format ppt169

# 2. (可選) 解析 PDF 或外部檔案並匯入專案
py skills/ppt-master/scripts/source_to_md/pdf_to_md.py source.pdf
py skills/ppt-master/scripts/project_manager.py import-sources projects/my_project source.md --move

Step 2: 由 AI 生成 SVG 內容

在 IDE 中呼叫 AI 助手，並要求：「請根據 my_project 的素材，幫我設計 5 張 Slate 900 深色風格的 PPT SVG 檔案，放入 svg_output 目錄，並把備忘錄寫入 notes/total.md。」

💡 AI 設計師技巧： 您可以隨時要求 AI：「幫我把第 3 頁加上一個流程圖」、「顏色改成科技藍」。AI 會直接修改本地的 SVG 檔案。

Step 3: 編譯與封裝 (Post-processing)

當 AI 幫您把 SVG 都寫好後，依序執行以下三支程式進行編譯：

# 1. 拆分講者備忘錄
py skills/ppt-master/scripts/total_md_split.py projects/my_project

# 2. 定稿 SVG (處理圓角、字型扁平化)
py skills/ppt-master/scripts/finalize_svg.py projects/my_project

# 3. 匯出為原生 PPTX
py skills/ppt-master/scripts/svg_to_pptx.py projects/my_project

完成後，PPTX 檔案會出現在 projects/my_project/exports/ 資料夾中。

5. API 金鑰與環境配置 (.env)

除了 GUI 介面外，您也可以在專案根目錄建立一個 .env 檔案來永久儲存配置：

# LLM 大腦配置 (擇一)
OPENAI_API_KEY=sk-xxxxxx
GEMINI_API_KEY=AIzaSy_xxxxxx

# AI 生成圖片配置 (需配合 image_gen.py 使用)
IMAGE_BACKEND=gpt-image-2

# 免費商業相簿配置 (推薦申請，提升配圖品質)
PEXELS_API_KEY=xxxxxx
PIXABAY_API_KEY=xxxxxx

# 語音旁白配置 (notes_to_audio.py 使用)
ELEVENLABS_API_KEY=xxxxxx

6. 進階功能與擴充

🎙️ 自動生成語音旁白與影片

系統可以讀取每一頁的 .md 備忘錄，並透過 AI 語音生成旁白，甚至自動配好時間軸匯出成影片。

# 生成語音旁白
py skills/ppt-master/scripts/notes_to_audio.py projects/my_project --provider edge-tts --voice zh-CN-XiaoxiaoNeural

🖼️ AI 圖片生成與搜尋

如果簡報中需要插圖，系統支援呼叫生圖模型，或是自動搜尋網路相簿。

# 使用 AI 生成圖片 (需配置 IMAGE_BACKEND)
py skills/ppt-master/scripts/image_gen.py --render-md projects/my_project/images/image_prompts.json

# 或使用相簿搜尋 (需配置 PEXELS_API_KEY)
py skills/ppt-master/scripts/image_search.py projects/my_project

✨ 模板復刻 (/create-template)

您可以提供任何一份喜歡的 PPTX 檔案，系統能分析其母片、主題色與版式，並抽取出專屬的版型，供未來生成時重複呼叫。

7. 常見問題排解 (Troubleshooting)

  • Q: 生成的 PPTX 檔案打不開或內容破圖？
    A: 這通常是因為 SVG 內包含不合法的 Unicode (如 &#25挑) 或包含了 HTML 實體。請確保 AI 生成的 SVG 是標準的 Raw Unicode。
  • Q: Web GUI 無法產生，一直轉圈圈？
    A: 請檢查命令列 (Terminal) 的錯誤日誌。90% 是因為沒有在設定中填寫正確的 API Key，導致後端呼叫 LLM 失敗。
  • Q: 如何修改生成的背景顏色？
    A: 使用 IDE 模式時，您可以直接修改 SVG 頂部的 <rect id="bg" fill="#0F172A"/>，然後重新執行 svg_to_pptx.py 即可生效。
