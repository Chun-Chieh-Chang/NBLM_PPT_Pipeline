✦ 功能特色

為什麼選擇 NBLM PPT Pipeline？

基於 PPT Master 引擎深度整合 Google NotebookLM 生態系，讓 AI 學習筆記瞬間蛻變為企業級精美投影片。

真正原生、逐字可編輯

拒絕靜態截圖！所有文字框、幾何背景、向量裝飾元素均為 PowerPoint 原生 DrawingML 形狀，打開即可滑鼠點擊直接編輯任何元素。

NotebookLM Podcast 語音對齊

智慧解析 Podcast Transcript 的說話者切片與字數占比，自動將音訊切片為每頁投影片的轉場語音，實現視聽同步簡報。

GUI 視覺化儀表板

內建 Flask Web 控制台，支援專案卡片管理、拖曳上傳素材、即時 SSE 串流終端日誌、一鍵自動生成簡報及環境配置，全程可視化操作。

NotebookLM 專屬解析

完美解析 FAQ 問答卡片、Study Guide 核心詞彙矩陣、Essay Questions 社論焦點等 NotebookLM 特殊格式，映射為精美諮詢卡片版面。

數據與隱私 100% 本地

除了與大語言模型的必要交互外，整個編譯、分割、SVG 圖形生成及 PPTX 匯出流程全部在您的本地電腦上執行，隱私完全受控。

一鍵啟動、零配置部署

雙擊 start.bat 即可自動偵測 Python、安裝依賴、部署環境並開啟瀏覽器控制台。全程引導提示，無需任何命令列知識。

🚀 安裝指南

三步驟即刻上手

從零開始，只需三個步驟即可在本地啟動完整的 AI 簡報生成工作台。

1

安裝 Python 3.10+

前往 python.org 下載並安裝 Python。安裝時請務必勾選 「Add Python to PATH」。

python --version
2

下載本專案

透過 Git 克隆或直接下載 ZIP 壓縮檔。解壓縮後進入專案資料夾。

git clone https://github.com/Chun-Chieh-Chang/NBLM_PPT_Pipeline.git
3

一鍵啟動

雙擊 start.bat 即可自動安裝依賴、部署環境並開啟瀏覽器 GUI 儀表板。

start.bat
🏗️ 系統架構

模組化的工業級管線設計

每一個模組職責單一、可獨立測試，透過流水線串接實現端到端的自動化簡報生成。

📥 素材解析引擎

支援 PDF、DOCX、Excel、網頁、Markdown 及 NotebookLM 匯出格式的智慧轉換，自動擷取結構化大綱。

🎨 SVG 向量繪製

AI 大語言模型驅動精美 SVG 頁面設計，內建即時預覽編輯器（Port 5050），支援所見即所得的視覺化微調。

⚙️ DrawingML 編譯器

將 SVG 精準轉換為 Office Open XML 的原生 DrawingML 形狀，確保每個元素在 PowerPoint 中 100% 可編輯。

🖥️ Web GUI 控制台

Flask 後端 + 前端視覺化儀表板，支援雙管線工作流（標準簡報 / NotebookLM 專項），即時 SSE 日誌串流。
