NATIVELY EDITABLE PPTX GENERATOR

PPT Master 使用說明手冊

歡迎使用 PPT Master，這是一個致力於實現「真正原生、元素級別可編輯」的 AI 簡報生成系統。它可以將您的 PDF、Word 檔案、Excel、網頁或 Markdown 即時轉化為擁有精美排版、高畫質 SVG 向量資產以及豐富動態特效的 PPTX 投影片。

為什麼選擇 PPT Master？它與傳統工具的本質區別
很多 AI 投影片工具（如 Gamma 等）雖然外觀精美，但匯出的 PPTX 往往「將整頁投影片打包成一張大圖片」，這使得使用者在本地 Office 中完全無法修改任何文字或圖形。PPT Master 透過將 SVG 轉換為 Office 原生 DrawingML 向量形狀，確保您的投影片每一個單詞、每一種配色、每一個圖示、甚至圖表資料點都可以使用滑鼠點選直接本地編輯與排版！

真實原生、逐字編輯

拒絕無用的靜態圖片！所有文字框、幾何背景、向量裝飾元素均為 PowerPoint 原生形狀，開啟即可編輯。

資料與隱私安全

除了與大語言模型（LLM）的必要互動外，整個編譯、分割、SVG 圖形生成及 PPTX 匯出流程全部在您本地電腦上執行，隱私百分之百受控。

強大的多引擎影象支援

整合 AI 生產模式（支援 gpt-image-2 等）以及多維度免版權庫搜尋（Pexels, Pixabay, Openverse），極致呈現專業雜誌質感。

2. Windows 環境部署

在 Windows 下安裝 PPT Master 只需要非常簡單的三個核心步驟。請確保嚴格遵循以下指南：

第 1 步：安裝 Python（核心硬性依賴）

  • 前往 python.org 官方下載頁面，下載最新版的 Python 3.10+ 安裝程式。
  • ⚠️ 極致關鍵：安裝時必須勾選 "Add python.exe to PATH"（將 Python 新增到環境變數）。這是 Windows 上最容易被忽略但最致命的錯誤。

第 2 步：安裝 Python 模組與核心依賴

在您的專案根目錄下開啟 PowerShell（在檔案總管地址列輸入 powershell 斷行），然後執行：

pip install -r requirements.txt

等待安裝結束。如果您的網路不佳，可使用國內映象加速（如清華大學映象源）：

pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

第 3 步：測試並驗證您的環境是否就緒

執行以下命令。若無報錯且順利輸出 All core dependencies OK，代表部署完好：

python -c "import pptx; import fitz; print('All core dependencies OK')"
驗證透過
大功告成！您現在已完成了 PPT Master 本地端最底層的執行時配置。接著讓我們來瞭解如何利用命令列控制它。

3. 核心命令手冊

在專案開發或手動生成中，我們提供了一系列輔助指令碼與管理工具。您可以根據分類進行命令搜尋與一鍵複製：

4. NotebookLM 深度整合與自動對齊

PPT Master 獨家支援與 Google NotebookLM 的端到端深度管道整合。能自動解析其匯出的結構化學習指南與對談 Podcast 語訊，一鍵合建同步演講的 DrawingML 投影片。

雙軌整合管線：文字結構化排版 + 音訊對談話題同步
本功能透過 方案 A（超輕量文字對齊技術），基於對談文字時間戳錨點與字數權重進行插值，生成最完美的換頁定時。同時將結構化內容轉化為專業的 諮詢卡片風 (Consulting Box) 佈局，兼備極致的閱讀感與視覺聽覺雙重饗宴。

🛠️ NotebookLM 核心整合指令碼

notebooklm_to_md.py

將 FAQ、Study Guide 的核心詞彙解析並對映為雙欄問答諮詢卡片、2x2 詞彙矩陣與社論問答焦點頁，自動加入雙位數順序標題字首防止 mismatch。

notebooklm_podcast_sync.py

分析雙人對話時間軸，在 pydub/ffmpeg 環境下進行音軌區域性物理切片；在無環境依賴時，將換頁時長精準定時引數直接注入 animations.json 中。

notebooklm_pipeline.py

一鍵封裝流水線，支援 --phase setup 自動生成 placeholder SVG 骨架和音訊分割，以及 --phase export 完成後製、扁平化文字並編譯匯出 PPTX。

📊 端到端一鍵整合命令指南

請將從 NotebookLM 右上角複製得到的 Study Guide Markdown 命名為 study_guide.md，Podcast 音訊命名為 podcast.mp3，對話文字存成 transcript.txt，放置於 projects/mock_notebook/ 下，接著在 PowerShell 中依序執行：

第一階段：專案初始化與音軌自動同步 (Phase A)

python3 skills/ppt-master/scripts/notebooklm_pipeline.py `
    --source projects/mock_notebook/study_guide.md `
    --podcast projects/mock_notebook/audio_overview.mp3 `
    --transcript projects/mock_notebook/transcript.txt `
    --project my_notebook_deck `
    --phase setup

該命令會自動在 projects/ 底下生成附帶日期時間戳的專案目錄，並在 svg_output/ 中為您自動生成 Consulting Box 瑞士網格佈局的 placeholder 簡報卡片骨架。

第二階段：後製處理與編譯匯出為 PPTX (Phase B)

當您對 svg_output/ 下的投影片外觀（漸層、卡片懸浮邊框、陰影等）使用 SVG 編輯器進行設計與精修後，執行以下指令完成 DrawingML 原生編譯：

python3 skills/ppt-master/scripts/notebooklm_pipeline.py `
    --project my_notebook_deck `
    --phase export

編譯完成後，您的 DrawingML 原生可編輯 PowerPoint 簡報將直接匯出於該專案下的 exports/ 目錄，雙人 Podcast 切片語音也已原生嵌入對應的投影片音訊元件中！

5. 完整工作流細節

PPT Master 擁有一套極其嚴密的流水線架構，各模組職責清晰分明。以下是生成簡報的核心邏輯：

1
Strategist 解析
解析原檔，規劃大綱及每頁版面架構，生成核心 Markdown
➔
2
Image 配圖
批次生成或搜尋免版權精美配圖，自動注入 icons 庫
➔
3
Executor 渲染
把文字、配色、佈局與配圖合成生成高保真 SVG 圖層
➔
4
PPTX 原生匯出
SVG 向量對映為 PowerPoint DrawingML 元素

四大關鍵角色與其職責

💡 1. 策略分析專家 (Strategist) — 「靈魂智囊」
當您丟入一個檔案（例如一個 50 頁的季度總結 PDF）時，Strategist 會率先啟動。它對長檔案進行精準去噪、抓取骨幹、重新組裝並輸出結構化的 PPT 內容大綱。在此階段它會遵循「八項黃金確認原則」，嚴格校正簡報的聽眾定位、主次配色方案、章節過渡頁設計以及資訊密度比率。

🎨 2. 創意藝術總監 (Image_Generator) — 「美學大師」
基於大綱規劃，藝術總監會為那些需要配圖、人物肖像、SaaS 介面截圖的投影片輸出一個 image_prompts.json 配圖清單（Manifest）。然後自動呼叫我們強大的圖片處理引擎，透過 AI 繪圖或免版權圖片庫獲取高畫質、色彩協調的實體資產，拒絕無意義的通用插圖。

⚡ 3. 渲染執行引擎 (Executor) — 「工程巨匠」
拿到文字大綱與精美配圖後，Executor 會自動將它們轉化為符合嚴格排版美學（諸如經典的瑞士網格系統、卡片微懸浮感、4px 間距對齊原則等）的高保真向量 SVG 原始碼。這一步奠定了投影片的前端骨骼。

📦 4. DrawingML 編譯器 (svg_to_pptx) — 「完美閉環」
最後，編譯器將 Executor 生成的 SVG 標記逐行解構，轉換為原生 Microsoft PowerPoint 的 DrawingML 程式碼。這意味著您在 PowerPoint 中可以直接選取這些向量幾何圖形，自由拉伸、無失真縮放、更換填充顏色，或將文字框內的任何一個拼寫錯誤一鍵修正！

6. 進階功能配置

除了基礎的檔案轉簡報，PPT Master 還支援一系列前沿的進階功能，讓您的簡報體驗宛如藝術大片：

一鍵複製品牌模板 (Template Replication)

您不再受限於系統內建的簡報風格！只需向 AI 提供一個您平時最喜歡的 .pptx 範本（例如您公司的官方商務模板），並在聊天面板中指示：

請透過 /create-template 將這個 pptx 複製為我的專屬模版

PPT Master 的底層解析引擎會直接分析該 Office XML 的配色體系、字型主次搭配、過渡頁與內容頁的網格骨架，將其解構為一個私有的模板套裝（存放於 skills/ppt-master/templates/brands/ 下），供後續生成任務一鍵套用！

即時視覺編輯 (Live Preview Workflow)

在簡報生成的流水線執行期間，系統會自動在本地 http://localhost:5050 啟動一個極簡奢華的 Web 預覽器。這也是我們最受歡迎的功能之一：

  • 視覺化選取：直接在網頁瀏覽器中用滑鼠點選您覺得排版不滿意、文字過多的區塊。
  • 撰寫修改要求：在側邊欄直接用中文輸入您的具體修改意見，如：「請把這個背景圓形改為皇家藍，並把這個標題放大到 28px」。
  • 提交註釋：點選 Submit annotations。
  • AI 熱過載：回到 IDE 聊天面板，直接輸入：apply my annotations。AI 便會自動重構對應的 SVG 並重新編譯為最新的 PowerPoint！

自動配音與 MP4 視訊匯出 (AI Narration & Cloned Voice)

想將做好的簡報直接發布到 YouTube、小紅書或用作內部員工培訓影片？沒問題！

  • 語音朗讀合成：PPT Master 可以自動抓取您寫在每張投影片下方的「演講備忘錄 (Speaker Notes)」，並自動呼叫 edge-tts 批次合成為高保真語音（支援 90 種以上的全球口音）。
  • 語音克隆 (Voice Cloning)：您甚至可以在 .env 中配置 ElevenLabs 等供應商 的金鑰，上傳您自己的短語音，讓生成的整套投影片以「您本人的專屬音色」進行沉浸式演講朗讀！
  • 影片自動同步：生成好的音軌會被原生地嵌入到 PPTX 的每頁音訊元件中，您只需在 PowerPoint 中點選「檔案 ➔ 匯出 ➔ 建立視訊」，即可得到一部音軌與頁面切換、動畫完美對齊的 MP4 簡報影片！

Agnes AI 智慧多模態路由

本專案原生支援 Agnes AI 的多模態模型，並且已經內建了無縫的自動路由機制：

  • 文字與網頁排版：只要在 .env 中配置了 AGNES_API_KEY，當您進行 Guizang 網頁版簡報 (Magazine / Swiss 格式) 生成時，系統會自動呼叫 agnes-2.0-flash 模型來處理複雜的文本與 HTML 邏輯。
  • 自動插畫生成：對於 PPTX 的視覺化影像，系統後端預設會自動切換並對接 agnes-image-2.1-flash，為您的簡報產生高解析度的精美背景或插圖。
  • 零手動切換：您不需要頻繁更改模型參數設定，Pipeline 已經完全理解何種任務該分配給哪一個模態，實現了真正意義上的全自動 AI 協同工作流程。

7. 常見故障排除

在部署或使用過程中，如果遇到了非預期的錯誤，請對照以下清單進行快速外科手術式排查：

故障症狀 1

PowerShell 提示「因為系統上已停用執行指令碼，所以無法載入...」

原因：Windows 預設的安全策略限制了本地 PowerShell 指令碼的啟動許可權。
修復路徑：以系統管理員身份開啟一個新的 PowerShell，然後執行以下命令以解鎖執行許可權：
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
故障症狀 2

執行命令時彈出「python was not found...」或自動開啟 Microsoft Store

原因：您的 Python 依然不在 Windows 的系統 PATH 環境變數中。
修復路徑：您可以手動將 Python 目錄加入環境變數：
  1. 在 Windows 搜尋欄輸入並開啟「編輯系統環境變數」。
  2. 點選「環境變數」按鈕。
  3. 在「使用者變數」或「系統變數」中找到 Path 專案並雙擊。
  4. 點選「新增」，填入您 Python 的具體安裝路徑（如 C:\Users\YourName\AppData\Local\Programs\Python\Python312）。
  5. 再次點選「新增」，填入 Scripts 目錄（如 C:\Users\YourName\AppData\Local\Programs\Python\Python312\Scripts）。
  6. 點選確定儲存，然後重新開啟 PowerShell 終端機使環境變數生效！
故障症狀 3

模組匯入報錯：「ModuleNotFoundError: No module named 'fitz'」

原因：PyMuPDF 的二進位編譯版本與當前 Python 發生衝突，或者 pip 未安裝正確。
修復路徑：透過強行指定預編譯輪子檔案安裝 PyMuPDF：
pip install PyMuPDF --only-binary :all:
故障症狀 4

重複刪除專案時控制檯出現 404，或背景指令輸出發生 Unicode 解碼錯誤

最佳化與原因：
  1. 非冪等 DELETE API 404：若專案在磁碟上已被成功刪除，重複傳送 DELETE 請求會回傳 404 造成前端 UI 報錯。我們已將該 API 重構為「冪等性 (Idempotent)」設計，已刪除的專案再次請求時將直接回傳 success，確保 UI 動態同步更新並消除 console 警告。
  2. 子程式 Windows 解碼錯誤：在 Windows (如 CP950/Big5 系統) 下，若子程式輸出特定的中文字元位元組且 Python 解碼器未指定容錯，會引發 UnicodeDecodeError。我們已在後端所有 subprocess 呼叫中加裝了 errors='replace' 解碼守衛，確保 100% 執行魯棒性。

9. NotebookLM MCP Server 整合指南

除了 CLI 管道整合外，您還可透過 MCP (Model Context Protocol) 讓 AI agent 直接呼叫 NotebookLM 的 32 個工具，實現更流暢的端到端工作流。

前置條件

  1. Trae IDE（基於 VS Code 架構）已安裝
  2. Python 3.10+ 已安裝
  3. uv 已安裝：pip install uv

Step 1: 安裝 notebooklm-py

pip install "notebooklm-py[browser,mcp]"

Step 2: 認證

notebooklm login   # 開啟瀏覽器進行 Google OAuth
notebooklm list    # 驗證認證是否成功

Step 3: 在 Trae IDE 中註冊 MCP Server

Trae IDE 使用 VS Code 的 MCP 配置格式。開啟設定 (Ctrl+,)，搜尋 "mcp"，新增以下設定：

{
  "mcpServers": {
    "notebooklm": {
      "command": "uvx",
      "args": ["--from", "notebooklm-py[mcp]", "notebooklm-mcp"]
    }
  }
}

Step 4: 重啟 IDE 並驗證

重新啟動 Trae IDE 後，在 AI 對話中測試：

使用者：用 NotebookLM 先分析 projects/my-project/sources/ 中的檔案

AI：
1. [透過 MCP] notebook_create("PPT-Analysis")
2. [透過 MCP] source_add(notebook="PPT-Analysis", source_type="file", path="./sources/report.pdf")
3. [透過 MCP] chat_ask(notebook="PPT-Analysis", question="請整理出 5 個關鍵洞察")
4. [結果] 將 Gemini 的分析結果餵入 SKILL.md Step 2

可用工具類別

類別 主要工具
Notebook 管理 create / list / rename / delete
來源管理 source_add / source_list / source_fulltext
聊天與研究 chat_ask / research_start / research_status
產物生成 studio_generate (podcast/video/slide-deck/report)
疑難排解
  • MCP Server 無法啟動：確認 uvx 可在 PATH 中找到：where uvx（Windows）
  • 認證過期：執行 notebooklm auth refresh 刷新
  • IDE 看不到工具：確認設定檔路徑正確，且 IDE 已完全重啟（非僅重新載視窗）
