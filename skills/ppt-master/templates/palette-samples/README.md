# CyberPPT Visual Palette Samples

This directory contains 8 fixed visual style samples from CyberPPT, designed for consulting-style presentations with high information density.

Each sample is a 16:9 aspect ratio image demonstrating a complete visual system including:
- Background color and surface system
- Typography hierarchy (C0/T1-T14)
- Chart language and data visualization style
- Information density and component layout
- Accent color usage
