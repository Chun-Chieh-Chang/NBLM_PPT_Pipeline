# 03_zhanpao_decode

[過渡] 讓我們把鏡頭拉近，解密這條戰袍。

它的色彩來自中國傳統的**五方正色**——**黃色**取自湖北神農架的**黃櫨**，代表土地；**青色**取自江南初春的**馬蘭草**，代表春天。這兩種植物，歷經熬煮、沉澱，最終化作流動的色彩。

更讓人驚歎的是它的染色工藝，叫做**"手工吊染"**。黃榮華在下面染，李子柒在上面拉繩子，**每隔三十秒往上拉一釐米**。[停頓]

就這樣一釐米、一釐米，布料在染料中緩緩升降，最終形成水墨暈染般的自然過渡。容不得半點差錯——這是對耐心與技藝的雙重考驗。

要點：① 五方正色的哲學寓意 ② 黃櫨與馬蘭草的原料溯源 ③ 吊染工藝的精準與浪漫
時長：1.5 分鐘

# 04_history

[過渡] 植物染這門技藝，不是李子柒這一代才有的。它的歷史，遠比我們想象的悠久。

史書記載：**"染色之術，遠始於軒轅之世，黃帝制定玄冠黃裳，以草木之汁，染成文彩。"**[停頓]

從**西周**設專職"染人"，到**秦朝**的"染色司"，再到**唐宋**的"染院"，**明清**的"藍靛所"——中國的染色技藝從民間手工逐步走向官營規模化。《齊民要術》《天工開物》《考工記》《大明會典》這些典籍，都系統記錄了植物染的技藝與工序。

一條長達數千年的染色之河，今天依然在李子柒的戰袍上流淌。

要點：① 染色史始於軒轅之世 ② 五個關鍵時代節點 ③ 古籍的系統記載
時長：1.5 分鐘

# 05_natural_colors_1

[過渡] 接下來，讓我們走進具體的色彩世界。我挑了四組代表性的傳統色來分享——先講兩種"自然之色"。

**第一種叫"雨過天青"**。它的名字來自宋徽宗的一句御批："**雨過天青雲破處，這般顏色做將來。**"這句話成就了青花瓷的至尊名號。[停頓]染法是土靛95%加上黃芩5%套染，清透之中帶著一絲朦朧詩意。

**第二種叫"蒼黃"**。這是報春鳥和小鹿身上的顏色。李昉《太平廣記》裡記載，顧渚山中有鳥，蒼黃色，每年正月二月叫著"春起也"，採茶人叫它"報春鳥"。染出這種蒼黃，可以用大黃加蘇木。

要點：① 雨過天青——宋徽宗御批，青花瓷色 ② 蒼黃——報春鳥之色 ③ 染料配方背後的文化典故
時長：1.5 分鐘

# 06_natural_colors_2

[過渡] 再講另外兩種——**"暮雲灰"**和**"天水碧"**。

**暮雲灰**是日暮時分雲彩呈現的那種暗紫紅的灰色。[停頓]李清照說"**落日熔金，暮雲合璧**"，柳永說"千里煙波，暮靄沉沉楚天闊"——古人用一個灰色，就寫盡了日暮時分的所有情緒。染法其實很簡單：蘇木加上藍礬和少許皂礬媒染。

**天水碧**則有一個動人的故事。南唐後主李煜的妃子，有一次把沒染好的絲帛放在院子裡露天過夜，絲帛沾上露水，竟然變成了鮮豔的綠色。李煜把這種意外之色命名為**"天水碧"**——一夜朝露，成就了一個色名。

要點：① 暮雲灰——詩詞裡的日暮情緒 ② 天水碧——一夜露水成色的意外美 ③ 古人為色命名的方式
時長：1.5 分鐘

# 07_poetic_colors_1

[過渡] 如果說剛才講的是"自然之色"，那接下來講的兩種，更像是"詩意之色"——它們不只是顏色，還承載著文學的意境。

**"銀紅"**，是一種淺緋色，像朝霞初染，又似桃瓣含霜。《紅樓夢》裡多次出現它——那個軟煙羅只有四種顏色：雨過天青、秋香色、松綠色，還有一樣就是**銀紅**，也叫"霞影紗"。[停頓] 黛玉窗前那一抹銀紅的霞影紗，正如絳珠仙草淚染的胭脂痕。

**"酡色"**，則是飲酒後臉上泛出的紅色。李白說："**美人慾醉朱顏酡**"。酡色讓人聯想到"貴妃醉酒"的場景——何等的嫵媚。

要點：① 銀紅——《紅樓夢》霞影紗之色 ② 酡色——美人微醺之色 ③ 顏色與文學意境的深度繫結
時長：1.5 分鐘

# 08_poetic_colors_2

[過渡] 再看另外兩種詩意之色——**"黛青"**和**"相思灰"**。

**黛青**，是從藍草中提取出的深青色。[停頓] 古代女子常用它來畫眉，所以黛青色總讓人聯想到美麗的女子。王實甫《西廂記》裡寫崔鶯鶯："**眉黛青顰，蓮臉生春，有傾國傾城之容**"——一個顏色，就描繪出了一位佳人。

**相思灰**呢，是一種帶有想象性的色彩。[停頓] 李商隱有一句詩叫"**春心莫共花爭發，一寸相思一寸灰**"。相思在心頭燃燒成灰燼，揮不開，散不去——若說顏色有情，相思灰則最為情深。染法是茶葉或石榴皮作染料，以少許皂礬媒染。

[互動] 大家有沒有發現一個規律？中國人給顏色起名，從來不只是描述色相，而是在講一個故事、一種情緒。

要點：① 黛青——古代女子畫眉之色 ② 相思灰——李商隱詩句催生的色名 ③ 中國傳統色的情感底色
時長：2 分鐘

# 09_dye_plants

[過渡] 講了這麼多顏色，大家可能想知道——這些顏色究竟從哪些植物裡染出來的？

答案其實很簡單：**花、果、葉、莖，都可以入染。**

**染紅色**的，有茜草的根、蘇木的莖稈、紅花的花瓣；
**染黃色**的，有槐花的花蕾、梔子的果實、薑黃的根莖；
**染藍色**的，有藍草、鼠李的葉和莖稈；
**染黑色**的，可以用胡桃、板栗的果殼。[停頓]

這四大色系，構成了中國傳統染色的基礎色盤。茜草、蘇木、紅花、槐花、梔子、薑黃、藍草、胡桃、板栗……這些名字聽起來普普通通，可一旦下到染缸裡，就會染出令人驚豔的色彩。

要點：① 四色對應的染料植物 ② 花果葉莖皆可入染 ③ 古法染色的"草木清單"
時長：1.5 分鐘

# 10_diy_dyeing

[過渡] 更讓我覺得美好的是——植物染不是博物館裡的技藝，它其實是普通人在家就可以嘗試的手作。

五個步驟：**燒一鍋水 → 投入染料 → 熬製一到兩小時 → 濾出染液，浸入布料 → 最後用陽光曬暖固定色彩**。[停頓]

進階一點的話，還有媒染、復染、氧化還原、套染這些技巧，可以透過不同顏色的疊加，創造出變化萬千的效果。

但植物染最吸引我的地方，其實不是技術——而是**它的不可控**。它的顏色有深有淺，有一些不完美的"瑕疵"，但每一次染色都獨一無二。[互動] 這是工業染法永遠無法企及的。

親手染色的過程，就像和植物在對話。**緊張焦慮的情緒，會漸漸消失不見**。你能在這裡看見一個安靜自在的自己。

要點：① 五步染色法，簡單易行 ② 進階技巧：媒染/復染/氧化還原/套染 ③ 手工的"瑕疵"即為獨一無二 ④ 染色作為自我療愈的過程
時長：2 分鐘

# 11_xuetaojian

[過渡] 分享最後一個故事——**薛濤箋**。

唐代才女薛濤，用浣花溪的水、木芙蓉的皮、芙蓉花搗汁為漿，染成了"芙蓉紅"色的信箋。[停頓] 這大概是中國文學史上最風雅的一抹顏色。

以新鮮花朵絞汁雖然也能染出芙蓉紅，但量小工繁，不太實用。按照黃榮華的經驗，**用蘇木作染料、明礬作媒染劑**，效果最好。

這就是傳統色的魅力——它不是博物館櫥窗裡的標本，而是可以在今天，被我們親手復刻、親身體驗的風雅。一張薛濤箋，千年不斷。

要點：① 薛濤箋的文學典故 ② 現代復刻的推薦配方 ③ 傳統色的"可復刻性"
時長：1.5 分鐘
